## 📋 Descripción
El proyecto resuelve la ineficiencia y desorganización de utilizar WhatsApp para la capacitación empresarial al centralizar y formalizar todo el proceso en una plataforma LMS. Soluciona la falta de control sobre los materiales educativos al estructurarlos en módulos y lecciones descargables, elimina el seguimiento manual mediante barras de progreso automatizadas, y sustituye la revisión informal por un sistema de quizzes con calificación automática.

- **Frontend:** React / Vue / Bootstrap
- **Backend:** Node.js + Express / Laravel / Django
- **Base de Datos:** MySQL / MongoDB
- **Despliegue:** Vercel / Railway / Render
