Problemática

La capacitación empresarial no puede seguir viviendo en WhatsApp

El cliente (CapacitaTec S.A.) capacitaba a su personal por mensajería instantánea: sin estructura, sin control y sin medición.

✕

Materiales sin control

No existe una biblioteca central: los contenidos se pierden o duplican entre chats y archivos sueltos.

✕

Seguimiento manual

Avance de cada alumno se rastrea a mano; es imposible saber quién va atrasado.

✕

Evaluación informal

Los quizzes se revisan a mano y sin calificación automática ni criterio uniforme.

✕

Desorganización general

Sin módulos ni lecciones estructuradas, cada curso depende de la memoria del instructor.

Descripción del proyecto

Una plataforma LMS que formaliza la capacitación

Centralizamos el proceso completo en una aplicación web: cursos organizados en módulos y lecciones descargables, progreso automatizado con barras de avance y quizzes con calificación automática e inmediata.

◈

Contenido estructurado

Módulos → lecciones con materiales descargables (PDF, video, ZIP, enlaces) y visor integrado.

◈

Seguimiento automático

Porcentaje de avance calculado en tiempo real por curso y por alumno, visible para ambos.

◈

Evaluación automatizada

Quizzes con puntaje, aprobación automática y tareas con entregas por parte del alumno.

Construido con React en el frontend, Node.js + Express en el backend y MongoDB como base de datos. (Detalle completo de versiones en diapositiva 8.)

Base de datos

MongoDB con Mongoose · 8 colecciones

Transacción real · Inscripción a curso

Al inscribirse, se crea un documento Inscripcion con alumnoId + cursoId. Un índice único compuesto impide inscribirse dos veces al mismo curso.

Transacción real · Progreso de lección

Al completar una lección, se agrega su ID a leccionesCompletadas, se recalcula el porcentaje y se actualiza ultimaActividad, con índice único alumno+curso.

Inscripcion Progress Evaluación Entregas
// models/Inscripcion.js const inscripcionSchema = new Schema({ alumnoId: { type: ObjectId, ref: 'User', required: true }, cursoId: { type: ObjectId, ref: 'Course', required: true }, activo: { type: Boolean, default: true } }); // Un alumno solo puede inscribirse una vez por curso inscripcionSchema.index( { alumnoId: 1, cursoId: 1 }, { unique: true });
// models/Progress.js const progressSchema = new Schema({ alumnoId: ObjectId, cursoId: ObjectId, leccionesCompletadas: [String], porcentaje: { type: Number, default: 0 }, ultimaActividad: { type: Date, default: Date.now } }); progressSchema.index( { alumnoId: 1, cursoId: 1 }, { unique: true });
Funcionalidad destacada

AulaBot · Asistente con IA

💬

Interfaz no convencional

No es una página aparte: es un widget flotante sobre toda la plataforma, que se abre desde un botón flotante (FAB) en cualquier pantalla.

⚡

Proveedor y modelo

API de Groq (compatible con OpenAI) con el modelo llama-3.3-70b-versatile, vía SDK oficial openai. Responde en español.

🎓

Cómo ayuda al alumno

Resuelve dudas de la plataforma (inscripción, progreso, quizzes, calificaciones) y, como recibe el contexto de la lección actual, también aclara dudas del contenido del curso.

Funcionalidad destacada

Reportes administrativos

Implementado

Reporte completo por alumno

Endpoint GET /api/v1/reportes/admin (solo rol admin, protegido por JWT) consolida progreso por curso y calificaciones por quiz con estado de aprobación.

Implementado

Dashboard con gráficas

El panel del administrador visualiza con Recharts: progreso promedio por curso, tasa de aprobación de quizzes y promedio por quiz, más el detalle por alumno.

En desarrollo

Exportación a Excel / PDF

La descarga de los reportes en formatos Excel y PDF está planificada como siguiente etapa; no está disponible en la versión actual.
